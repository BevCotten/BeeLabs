# BeeLabs Day 4 — Python Decisions and Virtual Stylist

## What I Built

I created Bee's Virtual Stylist, an interactive Python program that:

- Asks for the client's name, occasion, and weather
- Recommends an outfit using `if`, `elif`, and `else`
- Understands compound conditions using `and`
- Selects random accessories with `random.choice()`
- Generates a runway score with `random.randint()`
- Lets the client repeatedly restyle using a `while` loop
- Stops the program when the client approves using `break`

## New Python Concepts

- Conditional statements: `if`, `elif`, and `else`
- Compound conditions using `and`
- Flexible text matching using `in`
- Cleaning input with `.strip().lower()`
- Importing modules
- Lists
- Random selections
- `while True` loops
- Ending loops with `break`

## What I Learned

Python checks conditions from top to bottom, so specific combination checks must appear before general single-choice checks.

I also learned that loops make a program interactive by allowing an action to repeat until the user is satisfied.
