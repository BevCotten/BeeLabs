# BeeLabs — Day 3

## What I learned

Today I learned how to use for loops, range(), lists, and functions in Python.

I learned that range() can have a start, stop, and step. I can use a negative step to make a loop count backwards.

I also learned that Python list indexes start at 0.

## Something that made sense

A loop lets me give Python an instruction once and have it repeat that instruction.

Functions also make sense to me. I can define what I want a function to do and then call it when I need it.

I learned that I can give a function different information. For example:

welcome("Beverly")
welcome("Bee")
welcome("Developer")

The same function can produce different results depending on what I give it.

## Something that confused me

Indentation confused me at first. I accidentally put "BeeLabs launched!" inside my loop, so Python printed it after every number.

I also forgot a colon after a for loop and learned to look at Python's error message to figure out what was wrong.

Parameters and arguments were confusing at first, but I understand them better now.
