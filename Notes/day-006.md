## 🧠 Python Concepts I Practiced

### `while True`
Repeats a section of code until I tell Python to stop.

### `if`
Checks whether a condition is true.

### `else`
Tells Python what to do when the `if` condition isn't true.

### `break`
Exits the current loop and continues with the rest of the program.

### `try / except`
Allows my program to handle certain errors instead of crashing.

### `ValueError`
I encountered this when Python tried to convert text like `"two"` into an integer.

### `.lower()`
Converts text to lowercase so inputs such as `Python`, `PYTHON`, and `python` can be treated the same.
